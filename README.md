# 🎓 College Student Assistant Chatbot

An interactive, rule-based web chatbot built with **Python** and **Streamlit**. Designed for college students, prospective applicants, and faculty to instantly access key academic dates, campus policies, operating hours, and administrative procedures.

---

## ✨ Features

- 💬 **Interactive Chat Interface**: Modern web interface using Streamlit's native `st.chat_message` and `st.chat_input`.
- 🧠 **Smart Keyword Matching**: Fast, zero-latency rule engine matching query intents for over 20+ college topics.
- 📌 **Topic Directory**: Sidebar topic explorer listing all supported subjects and guidelines.
- ⏰ **Real-Time Date & Time Integration**: Returns live system timestamps and date information.
- 🔄 **Session History Management**: Preserves conversation state and includes a one-click history clear button.

---

## 📌 Supported Topics

The assistant can answer inquiries regarding:

| Category | Topics Included |
| :--- | :--- |
| **Academics & Schedule** | Admission, Semester Dates, Exams, Timetable, Assignments, Attendance |
| **Campus Facilities** | Library Timings, Hostel Applications, College Hours, Transport, ID Card |
| **Administrative & Career** | Tuition Fees, Scholarships, Placements, Faculty Directory, Contact Info |
| **General Assistance** | Today's Date, Greetings, Leave Applications, Campus Events, Exit Commands |
